# Mega Murder Engine

This repo is the continuation of the game engine build for a game called 'Mega Murder' that I built alongside three others for a university course. The final game engine did not have all the features we had wanted from the start, so this is my attempt to finalize the engine we were building. The name **Mega Murder Engine** (MME) is a placeholder.

## What is MME

MME is a game engine built from scratch for our game Mega Murder, which you can find [here](https://github.com/SebLore/DV1504_LitetSpelProjekt_MegaMurder). The game was built to be a level-by-level fast-paced shooter in the style of Doom and Quake, with initial inspiration (including the name) taken from [Ultrakill](https://store.steampowered.com/app/1229490/ULTRAKILL/).
